# 행운사주 (Fortune Saju) — 무료 광고형 공개 테스트 버전

회원가입, 로그인, 결제, AI 상담 없이 이용하는 웹앱입니다. 광고 영역은 **두 곳**만 배치했고 실제 광고 코드는 넣지 않았습니다.

## 기능
- 양력/음력/윤달 변환, 출생 시각(10분 단위) 또는 생시 미상, 선택적 성별
- 절기 기준 연주·월주, 일주·시주, 오행·십성·천을귀인·대운 계산
- 실제 계산된 명식을 바탕으로 성격·평생운·오늘의 운세 6항목·신년운세 6항목을 규칙 기반으로 풀이
- 1~45 중 중복 없는 행운번호 6개
- 출생 정보는 서버에 저장하지 않음

## 정확성 및 한계
- 출생일 1962~2049년 지원. 한국표준시 UTC+9, 일주는 자정에 전환, 자시는 23:00~00:59.
- 연주: 입춘 기준, 월주: 12절 기준. 음력 변환: korean-lunar-calendar, 절기: pyswisseph.
- 대운은 순역행 및 절입 시각을 3일=1년 방식으로 계산. 성별 미입력 시 대운은 표시하지 않음.
- 오행은 표면상 8글자의 단순 개수로 신강·신약/용신 판정이 아님.
- 자동 회귀 테스트가 있지만 전체 날짜에 대해 독립 만세력 교차 검증은 미완료.
- 상세 운세는 현재 규칙 기반 테스트 해설이며 250단어의 AI 생성 심화 해설이 아님.
- 운세는 전통 문화·오락 및 자기성찰용이며 결과를 보장하지 않음.

## GitHub 및 Render 공개 배포
ZIP 압축을 해제한 뒤 `fortune-saju2` 폴더 **안에 있는 파일과 폴더 전체**를 GitHub의 새 `fortune-saju2` 저장소 최상위에 업로드하세요. ZIP 파일 자체를 GitHub에 올리는 것이 아닙니다.
GitHub의 `Add file → Upload files`로 업로드한 뒤 `Commit changes`를 누르세요.
Render에서 `New → Blueprint`를 선택해 저장소를 연결하면 `render.yaml` 설정으로 배포됩니다.
무료 Render 인스턴스는 장시간 이용하지 않으면 대기 상태가 되어 첫 접속에 시간이 걸릴 수 있습니다.
공개 URL은 Render 배포가 성공한 후에만 생성됩니다.

## v2 개선 (기존 공개 사이트 업데이트)
- 무료 평생사주를 10년 단위 카드로 분리해 가독성 개선
- 일간·월주·일지·오행·천을귀인 해설을 실제 계산값 기반으로 확장
- 절기 시각은 한국시간 분 단위로 표시하고 세부 계산 근거는 펼치기 형태로 제공
- 명식 엔진 및 기존 URL은 변경하지 않음. 기존 GitHub 저장소의 파일을 같은 경로로 덮어쓰면 Render 자동 배포로 갱신 가능

## 별도 테스트 배포 안내
기존 fortune-saju 사이트는 그대로 두고 fortune-saju2를 별도 GitHub 저장소 및 별도 Render Web Service로 배포하세요. 새 저장소에 파일 전체를 올린 뒤 Render에서 새 Web Service를 만들고 서비스 이름을 fortune-saju2로 설정하세요. 기존 서비스의 render.yaml만 수정해도 기존 서비스 이름이나 주소가 자동 변경되는 것은 아닙니다.
